# League of Legends Performance Analyzer

A Python project for recording and analyzing League of Legends match performance.

## Planned Features

- Record match results and champion selections
- Calculate kills, deaths, assists, and KDA ratios
- Calculate overall and champion-specific win rates
- Summarize player performance across multiple matches
- Save and load match history

## Technologies

- Python 3
- Python standard library
